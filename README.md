# QUICSharp.Natives

This is a simple nuget package that wraps the native [msquic](https://github.com/microsoft/msquic) library in a NuGet package for use in .NET projects.


Currently supported platforms:
- [x] Linux x64
- [x] Windows 11 x64 (not bundled - supported on Windows 11 out of the box)
- [ ] Windows 10 x64

<br><br>

See: https://www.nuget.org/packages/YellowDogMan.QUICSharp.Natives
